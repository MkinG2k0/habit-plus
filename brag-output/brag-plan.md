# habit+ — usage demo video

## Angle
Короткое демо базового использования: создать привычку вручную, отметить дни, добавить из шаблона, переключить виды.

## Hook
Пустой экран → «Новая привычка» — за 2 секунды ясно, что это трекер привычек.

## Highlights
1. Форма: имя, описание, цвет
2. Отметка дней в списке
3. Быстрый старт из шаблона
4. Три вида: карточки / список / колонки

## Punchline
habit+ — привычки без лишнего.

## Tone
`app-store` — чистый product walkthrough, спокойный темп, читаемые подписи.

## Format
- Vertical 1080×1920 (9:16) @ 30fps
- Длительность ~40s (usage demo, не тизер)
- Phone frame по центру, подпись сверху

## Visual identity
- Font: Roboto Condensed
- Brand: habit+ (chart accent)
- Background: soft off-white with subtle grain
- Real app UI only

## Music
~100 BPM soft electronic pulse; clicks on beat; no vocals.
