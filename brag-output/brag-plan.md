# habit+ — usage demo video (v2)

## Angle
Онбординг через квиз баланса сфер → рекомендуемые КОДы → отметки дней → виды → настройки.

## Format
- Vertical 1080×1920 (9:16) @ 30fps, silent
- Phone frame, static captions

## Путь по экранам

1. `/quiz` intro — «Баланс сфер жизни» (Начать квиз / Импорт таблицы клуба / Пропустить)
2. `/quiz` вопрос 1 — первый вопрос со шкалой ответов
3. `/quiz` прогресс — ~14/38, карьера и др. сферы
4. `/quiz` результат — donut «Твоё внимание к сферам»
5. `/quiz` рекомендации — список рекомендуемых КОДов + «Добавить выбранные»
6. `/` grid — привычки после квиза
7. `/` list — «Последние 5 дней»
8–10. list — отметки дней (последовательные кадры)
11. HabitDetailDrawer — детали привычки + календарь
12. `/` cols — колонки
13. `/` grid — карточки
14. `/` + PWA-баннер «Установить habit+»
15. `/settings` — «Установка и офлайн» + Установить
16. `/settings` — пункт «Квиз баланса сфер»
17. `/` outro — habit+

## Timing
- Простые экраны — короткие (~1–1.5s)
- Сложные (результат квиза, рекомендации, детали) — длиннее (+0.3s hold)
